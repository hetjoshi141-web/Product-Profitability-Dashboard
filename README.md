# Product Profitability Dashboard

## Project Overview
This dashboard analyzes product profitability using Python, Pandas, Plotly and Streamlit.

## Features
- Product Profitability Overview
- Division Performance Dashboard
- Cost vs Margin Diagnostics
- Pareto Analysis
- Interactive Filters

## Tools Used
- Python
- Pandas
- Streamlit
- Plotly
